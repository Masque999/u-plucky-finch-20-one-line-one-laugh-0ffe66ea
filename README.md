# One Line, One Laugh

One funny line, at most 200 characters.

Entry: `I asked my agent for a summary and it gave me a 40-page report titled 'Summary', then asked if I wanted the long version.`

Run: `python3 main.py` (writes the line to `/output/entry.txt`).
